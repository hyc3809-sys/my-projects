# NGSL 721 트레이너

NGSL-Spoken 1.2(구어 핵심 단어 721개)를 말하기 중심으로 익히는 단일 HTML 학습 앱임.

## 구성
- `index.html` — 앱 본체. 브라우저에서 바로 열어도 동작함(진행 상황은 브라우저 저장소에 저장, AI 회화는 claude.ai에서 열었을 때만 사용 가능).
- `data/ngsl-spoken-721-ko.tsv` — 721개 단어 + 범주 + 한국어 뜻 + 회화 예문(영/한).
- `data/core-phrases-ko.tsv` — 핵심 회화 표현 94개(12개 기능 그룹).

## 기능
- 어휘 진단: 50개 표본으로 아는 단어 수 추정, 또는 721개 전체 분류
- 카드 학습: 한국어 뜻 + 예문 빈칸 → 영어 단어 말하기, 간격 반복(SM-2 변형)
- 핵심 표현 섀도잉: 음성 합성으로 듣고 따라 말하기
- AI 회화: 상황별 대화 + 매 문장 교정(721개 단어 위주)
- 커버리지 측정: 임의 영어 텍스트에서 721개 단어 비율과 목록 밖 단어 표시

## 주의
- "721개 = 일상회화 90%"는 토큰 커버리지 90%를 뜻함(10단어 중 1단어는 모름). 근거와 해석은 앱의 "학습법·근거" 탭 참조.
- 한국어 뜻·예문·표현은 AI가 작성한 내용이며 오류가 있을 수 있음.
